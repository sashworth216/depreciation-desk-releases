# Depreciation Desk releases

Installers and update information for Depreciation Desk, fixed asset depreciation software for CPA firms.

- Download the latest Windows installer from the **Releases** page.
- Installed copies check `latest.json` on the latest release once a day for updates. Update information is signed; the app ignores anything that is not.

This repository contains release files only, no source code. Depreciation Desk is proprietary software; see the license agreement shown during installation.
